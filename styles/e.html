Style 6 — Popup Navigation

Use the button to switch between mobile and desktop preview.

A lightweight and modern navigation pattern designed for compact mobile interfaces. On smaller screens, the standard navigation transforms into a hamburger menu that opens a small popup panel, providing quick access to navigation links while preserving valuable screen space.

The menu closes automatically when a navigation item is selected, the hamburger button is toggled, the user taps outside the popup panel, scrolls the page, or uses the ESC key, ensuring a smooth and intuitive mobile experience.
