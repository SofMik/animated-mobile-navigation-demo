Style 3 - Slide from Left

Use the button to switch between mobile and desktop preview.

A clean and practical navigation pattern designed for slide-in mobile navigation. On smaller screens, the standard navigation transforms into a hamburger menu that opens a vertical panel from the left side, providing easy access to navigation links while preserving screen space.

The menu closes automatically when a navigation item is selected, the close button is pressed, the hamburger button is toggled, the user taps outside the panel, scrolls the page, uses the ESC key, or performs a swipe-left gesture, ensuring a smooth and intuitive mobile experience.
