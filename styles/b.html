Style 7 — Bottom Navigation Menu

Use the button to switch between mobile and desktop preview.

A modern navigation pattern designed for fast and convenient mobile browsing. On smaller screens, the standard navigation transforms into a semi-transparent bottom navigation bar with rounded buttons, providing quick access to key sections while preserving valuable screen space.

The navigation bar remains fixed at the bottom of the screen for easy reach and automatically hides while scrolling down to maximize visible content. It reappears when scrolling stops or when the user scrolls upward, helping maintain a clean and distraction-free interface.

Raised buttons, active-state highlighting, and subtle ripple effects provide clear visual feedback and create a familiar mobile experience.
