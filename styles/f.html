Style 2 — Fullscreen Menu

Use the button to switch between mobile and desktop preview.

A bold and modern navigation pattern designed for full-screen mobile experiences. On smaller screens, the standard navigation transforms into a clean hamburger menu, providing quick access to all sections through an immersive full-screen interface.

The menu closes automatically when a navigation item is selected, the close button is pressed, the ESC key is used, or a swipe-down gesture is performed, creating a natural and intuitive mobile experience.
